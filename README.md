## Featured Project — Clanker

> Open source AI chatbot platform built in public. Users create custom AI characters and chat with them using Google Cloud Vertex AI. Firebase + Cloud SQL backend with subscription-based access control, persistent memory, and cross-platform support on iOS, Android, and web.

**[clanker-ai.com](https://clanker-ai.com)** · [GitHub](https://github.com/equationalapplications/clanker) · [App Store](https://apps.apple.com/us/app/clanker-ai/id6754219831) · [Google Play](https://play.google.com/store/apps/details?id=com.equationalapplications.clanker)

- Custom AI character creation with personality & persistent memory
- Image generation and avatar gallery
- LLM Wiki Memory — structured, queryable facts & episodic events
- Stripe subscriptions with cross-platform access control
- Spec-driven development with AI agents
- Stack: React Native · Expo · TypeScript · Vertex AI · Claude · Firebase · PostgreSQL · Stripe
