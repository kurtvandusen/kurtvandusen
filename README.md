## What I'm Building

### [Clanker](https://equationalapplications.com/products/clanker/) — Personal AI Companion

Talk to your custom AI character in real time, just like a phone call — with a memory that never forgets.

- Real-time Gemini Live voice — interrupt mid-sentence, hands-free on echo-cancelled speakerphone
- LLM Wiki persistent memory across sessions
- Document upload, live web search, browser bridge, and edge agent tools
- iOS, Android, and web · processed through Vertex AI, never used to train foundation models

[clanker-ai.com](https://clanker-ai.com) · [Real-Time Voice](https://clanker-ai.com/real-time-voice) · [GitHub](https://github.com/equationalapplications/clanker) · [App Store](https://apps.apple.com/us/app/clanker-ai/id6754219831) · [Google Play](https://play.google.com/store/apps/details?id=com.equationalapplications.clanker)

### [LLM Wiki Memory](https://equationalapplications.com/products/memory/) — Agentic Memory Platform

Platform-agnostic TypeScript engine for hybrid LLM memory — semantic search, ontology graphs, and episodic fact extraction over SQLite. Powers Clanker; published on npm as `core-llm-wiki`, `expo-llm-wiki`, `react-llm-wiki`, and `core-llm-tools`.

[Product Page](https://equationalapplications.com/products/memory/) · [core-llm-wiki on npm](https://www.npmjs.com/package/@equationalapplications/core-llm-wiki) · [GitHub](https://github.com/equationalapplications/expo-llm-wiki)
